## Units 09-15

Accuracy and conformance review. Validator status at finish: 0 schema errors, 0 lint errors, 0 warnings for units 09-15 (the only remaining course warning is unit 07, outside this review). Every lesson keeps 4 or more activities, payloads stay unique, and all edits were made by hand with Edit. New or fully rewritten activities got new ids; in-place corrections kept theirs.

- Diagram ids: hotspot-taps used undeclared ids (`basketball-court-horns`, `basketball-court-pnr`, `standings-table`, `playoff-bracket`) and one invented asset (`diagrams/college-basketball-landscape.svg`). - Opinion debates keyed as graded "best" answers (MVP, tanking, GOAT, star treatment) were rebuilt so the graded choice is a conversation move or a fact, not a verdict on the argument (CDS section 5: GOAT and MVP are not gamified).
